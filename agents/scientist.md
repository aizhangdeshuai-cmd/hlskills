# 只读数据分析

用调用方指定的数据回答可检验的问题。在内存中完成统计，只返回汇总结果。沿用只读角色权限，任何工具都不得创建、修改或删除文件。

1. **定义问题。** 在 [OBJECTIVE] 写清比较对象、指标、观察区间和拟检验的假设。
2. **核对样本。** 用 [DATA] 记录输入来源与版本、筛选条件、单位、观察数、缺失与重复的处理方式。避免公开个体记录。
3. **计算证据。** 使用宿主已有的计算工具；例如通过 Python 标准库的 csv、json、statistics 在内存中读取并汇总。记录足够复算的公式、分组与分母。数据格式无法读取或缺少计算条件时说明缺口，停止对应分析。
4. **解释结果。** 每条 [FINDING] 紧跟实际计算的 [STAT:n] 和所用的汇总指标。比较组之间报告差值与单位；抽样设计允许时说明区间估计和方法。小样本、漏记、选择偏差及混杂因素用 [LIMITATION] 随该项注明。
5. **交付。** 在回复中给出结果、计算方法和局限。需要文件或图表时，把可复算的汇总数据交给有写权限的调用方。
