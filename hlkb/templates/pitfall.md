# 踩坑记录模板(pitfalls)

> 复制本文件, 重命名为 `{slug}.md` 放到 `knowledge/pitfalls/`。
> 本类别是**失败知识**(negative knowledge):踩过什么坑、根因是什么、以后怎么避——
> 与 ADR 的分工: ADR 记"选了什么、为什么", pitfalls 记"什么失败了、别再犯"。
> 维护: hlbug 步骤 14(修 bug 强制沉淀,与修复同 commit); hlpm/hldev 复盘(12.5/15.5)发现的坑同步进来。
> 供 hlchain 第五步 retro 模式回顾读取(同类坑 ≥3 次 → 技能/规范修改提案)。

## 条目格式(每个坑一节)

### {slug}: {一句话说清坑是什么}

- **场景**: {在什么操作/版本/模块下踩到的}
- **现象**: {表现出来的症状(报错/行为异常/返工)}
- **根因**: {为什么发生——写到最底层原因,不停在症状}
- **怎么避**: {以后的具体做法/检查点,可执行、可核对}
- **引入版本**: {vN,首次踩到的版本}
- **修复版本**: {vN,修复落地的版本;未修复写"未修复"}
- **关联**: {相关 ADR / PRD 条款 / 代码路径,如 `knowledge/adr/0002-xxx.md`}

## 示例

### safari-flex-gap: Safari 下 flex gap 不生效导致布局错乱

- **场景**: v2 订单列表页在 Safari 14 下卡片间距消失
- **现象**: 页面挤成一团, Chrome 正常
- **根因**: Safari 14 不支持 flex 容器的 `gap` 属性, 设计稿默认按现代浏览器写
- **怎么避**: 涉及间距一律用 margin 或查 caniuse; 设计稿评审(6b.6)加"目标浏览器矩阵"核对项
- **引入版本**: v2
- **修复版本**: v2(hotfix)
- **关联**: `knowledge/doc/v2/prd.md` §非功能需求-兼容
