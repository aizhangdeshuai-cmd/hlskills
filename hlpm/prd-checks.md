# 功能卡评审

| 强制规则 | 写法与完成判据 |
|---|---|
| STD-001 功能唯一编号 | 逐一核对功能清单、卡片标题和交接矩阵。每个 BL 只定义一次，迭代继承原 ID，章序变化不重排 BL。 |
| STD-002 字段完整性 | 每个受影响的页面字段有可定位的字段编号、业务定义及控件行为，共用字段引用原定义。逐项核对页面、弹窗、列表和接口可见结果。 |
| STD-003 逻辑完整性 | 从每项操作沿触发条件找到对应 BR、界面响应、状态和持久化数据的变化，指明结果归属和下游；有计算时给出输入与结果样例。 |
| STD-004 异常完整性 | 逐项核对适用的失败、边界和恢复路径，每项给出触发、反馈、数据后果、恢复操作和验收依据。 |
| STD-005 可验收性 | 每个 BL 至少有一条可执行 AC，以具体前置、动作、可核对的结果验收。沿 BL → 字段/BR → AC → 场景或 TC 可追踪；未确认的预期标 TBD，受阻的 AC 不能计为通过。 |
