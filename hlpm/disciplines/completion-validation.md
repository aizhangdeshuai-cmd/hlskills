# 完成前验证

| 阶段 | 凭什么确认交付 |
|---|---|
| 需求分析 | 用户已给的决定、生效条款及明确移出本期的记录可以回查。 |
| PRD | 执行[本阶段检查](../SKILL.md#需求与-prd)，核对实际正文、编号和产品附件；复算关键数值，确认业务场景能检出错误行为。 |
| 原型 | 在浏览器从实际入口办理，核对反馈、数据和恢复，运行[逐 AC 实测检查](../design-stage.md)。截图、模拟及候选待验按实际范围记录。 |
| 验收标准与用例 | 执行[测试阶段检查](../SKILL.md#验收用例与交付)，确认每个编号对应可以执行和判断的用例，检查预期及同版链接。 |
| 正式交接 | 用[交接检查器](../handoff-package.md)复核本版原件、适用证据及摘要。评审记录写实际参与者和结论。 |

读取命令输出、退出状态与失败位置。缺证据时记录未验证范围及补验动作，修复后重跑。使用 Git 的项目核对本次实际差异，产品产物只写到约定位置；发现生产源码已有改动时保留并报告归属不清的差异。

本期业务问题回到[需求澄清](../SKILL.md#需求澄清)。同一争议被驳回三轮仍未解决时，列出各方意见、依据和会改变的结果，交用户裁决。
