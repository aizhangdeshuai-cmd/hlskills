# 产品阶段分工

产品阶段在本版目录编写需求、产品分册、可操作原型和验收材料。设计包可包含 HTML、样式、演示脚本、脱敏样例及验证资源。生产工程修改交由 [hldev](../../hldev/SKILL.md) 承接。

| 角色 | 负责的工作 |
|---|---|
| 产品 `analyst` | 需求分析、业务预期、PRD 起草。只读角色把草稿或评审意见交给主代理写入；`planner` 可补充规划依据。 |
| UI `designer` | 核对现有设计基线，制作版本内的交互原型与状态，复核可操作性。 |
| 开发 `executor` / `architect` | 评估实现可行性、组件复用、数据和接口影响，返回意见。 |
| 测试 `test-engineer` / `qa-tester` | 审查可验证性，编制本版验收用例或复演业务场景。 |
| 验证 `verifier` | 只读核对业务条件、同版证据和正式交接矩阵，记录通过、失败或待验证。 |
| 用户或指定决策者 | 确认本期业务、竞品取舍、跳过的阶段、各节点评审及修订后的下一步。 |

实际参与者取决于[各阶段评审选择](../SKILL.md#角色与评审记录)。完整交接在步骤 12 更新需求和用例的[知识库](../../hlkb/SKILL.md)索引，12.5 记录本版复盘。
