# 项目记忆建档模板

在 `.hl/memory/` 内按实际需要选用以下文件。填写已核实的项目内容，已有长期记录时引用原文位置。

## project.md

```markdown
# 项目记忆

## 基本信息
- 项目名称、目标、关键干系人、约束条件

## 当前阶段
- 阶段、活跃分支、最近里程碑及依据
```

## techstack.md

```markdown
# 技术栈

## 前端
- 框架、UI 库、状态管理及版本依据

## 后端
- 语言与框架、数据库、ORM 及版本依据

## 基础设施
- 部署、CI/CD、监控及配置位置
```

## architecture.md

```markdown
# 架构决策

## 模块划分
- 模块职责、入口目录及调用关系

## 关键 ADR
- 决策主题及生效范围，引用 knowledge/adr/ 中的原件

## 数据流
- 一条实际业务路径经过的组件与数据存储
```

## conventions.md

```markdown
# 约定与规范

## Git
- 提交、分支及合并约定

## API
- 命名、错误格式及鉴权

## 数据库
- 迁移和兼容要求

## 编码
- 项目已有的命名与静态检查规则

## 部署
- 交付检查和健康检查入口
```
