# 项目记忆与工作记忆

接续任务先读项目的 `.hl/memory/working.md`。从下一步或阻碍定位到对应证据，只打开继续工作所需的原件。旧记录缺少证据位置时，核实后补入。查询项目长期事实用 [hlkb](../hlkb/SKILL.md) 定位 `knowledge/` 中的原文。

## 保存与交接

完成阶段或交给下一位时，更新同一个 `working.md`。已确认且会复用的工程事实写入对应知识条目，在工作记忆里引用其位置。未解决的问题留在工作记忆。

```markdown
# 工作记忆

## 当前任务
- 正在做什么及已完成哪一步
- 证据位置（项目相对路径、章节或用例编号，需要时附版本或提交）
- 下一步及其预期结果

## 待办与阻碍
- 待验证的问题、依赖或需谁作决定
```

## 首次建档

首次需要交接时创建 `.hl/memory/` 并写入 `working.md`。只有要建立或补充项目概览、技术栈、架构、约定时才读[对应建档模板](references/project-files.md)。老项目的 `agents.md` 仍可按需查阅角色分工。
