# hldesign ── hlskills UI/UX 设计

加载 `hldesign` 子技能(SKILL.md 在 `hlskills/hldesign/SKILL.md`),按其规范执行。

## 设计依据优先级(源 SKILL.md L22-37)

### 1. 有设计规范文档(严格遵循)

- 项目根有 `design/spec.md` 或同级设计规范文件
- **直接读规范** + 严格遵循字号/色值/圆角/间距(硬性字面遵循,**1px 偏差都评审不通过**)

### 2. 无设计规范文档(询问用户偏好 + 推导设计系统)

- 用 `AskUserQuestion` 问 3 个问题:
  - 行业(金融/电商/SaaS/工具等)
  - 风格倾向(极简/专业/活泼/严肃)
  - 参考产品(如钉钉/Notion/Linear)
- 基于回答推导设计系统(L43-103)

## 设计系统推导(无既有规范时,L43-103)

### 0. 先避坑:LLM 设计默认偏见

- 不要默认"白底 + 蓝主色 + 12px 圆角" — 这是 LLM 默认输出,不是设计选择
- 每个行业有不同最佳实践

### 1. 色彩体系

- **主色 1 个**(品牌色)+ **辅色 2-3 个**(状态/强调)+ **中性色 5-7 个**(灰阶)
- WCAG 2.2 AA 对比度 ≥ 4.5:1

### 2. 字体系统

- 中英文混排(中文用苹方/思源黑体/阿里巴巴普惠体,英文用 Inter/Manrope)
- 字号阶梯(12/14/16/18/20/24/30/36/48)

### 3. 间距系统

- 4 的倍数(4/8/12/16/24/32/48/64)
- 不出现 5px/7px 等"奇数间距"

### 4. 圆角与阴影

- 圆角阶梯(0/2/4/8/12/full)
- 阴影层级(0/1/2/3 共 4 级)

## 设计原则(源 SKILL.md L156-179)

### 5 态覆盖(统一锚点,L161-170)

每个交互组件必须覆盖 5 态:

| 态 | 含义 | 视觉变化 |
|---|---|---|
| **默认** | 静态 | 基准色 |
| **悬停** | 鼠标进入 | 轻微变深/亮 |
| **激活** | 点击瞬间 | 明显加深 |
| **聚焦** | 键盘 Tab | 焦点指示器(2px 描边) |
| **禁用** | 不可用 | 灰阶 + 不可点击 |

### 设计评审自查清单(8 项)

1. 色彩符合设计系统(无野生色)
2. 字号符合阶梯
3. 间距符合 4 倍数
4. 圆角符合阶梯
5. 阴影层级正确
6. 5 态全覆盖
7. 无障碍达标(WCAG AA)
8. 设计稿含 DEV-NOT-FOR-PROD 标注(设计与实现分离白名单)

## 行业→设计系统映射参考(L107-123)

| 行业 | 主色 | 风格 |
|---|---|---|
| 金融 | 深蓝/绿 | 严肃、专业 |
| 电商 | 暖色 | 活泼、引流 |
| SaaS | 蓝/绿 | 专业、效率 |
| 工具 | 灰 + 单色强调 | 极简、专注 |

## 反模式库(各行业通用,L124-138)

- **彩虹页面**:5+ 主色并列,无主次
- **灰色地狱**:全部用灰阶,失去品牌
- **过度阴影**:每个元素都浮起,失去层级
- **奇数间距**:5px/7px/13px 等脱离栅格

## 无障碍要点(设计阶段,L180+)

- 对比度 ≥ 4.5:1(WCAG 2.2 AA)
- 目标尺寸 ≥ 24x24px(触屏可达)
- 文本替代(图标/图像)
- 焦点可见性
- 详见 `hla11y` 子技能

## 与 hla11y 关系

- `hldesign` = 通用设计规范
- `hla11y` = 专攻 WCAG 2.2 AA 无障碍
- **重叠部分**:无障碍要点同时在两边出现,设计阶段先看 `hldesign`,无障碍深度检查看 `hla11y`

## 调用方式

- **无实参**: 询问用户需求类型 + 是否有现有设计文档
- **有实参**(如 `/hldesign 设计登录页`): 进入设计 5 态检查
