## 通用质量规则(强制覆盖维度)

### 10 项必含(L62-75)

| # | 维度 | 含义 |
|---|---|---|
| 1 | 功能正确性 | 业务规则全覆盖 |
| 2 | 边界条件 | 空 / 极值 / 跨阈值 |
| 3 | 异常路径 | 错误码 / 状态冲突 / 资源耗尽 |
| 4 | 性能 | 响应时间 / 并发 / 资源占用 |
| 5 | 安全 | SQL 注入 / XSS / CSRF / 鉴权绕过 |
| 6 | 兼容性 | 浏览器 / OS / 屏幕尺寸 |
| 7 | 无障碍 | WCAG 2.2 AA(详见 `hla11y`) |
| 8 | 数据一致性 | 跨表事务 / 缓存失效 |
| 9 | 回归 | 受影响模块完整覆盖 |
| 10 | 用户体验 | 加载/交互/反馈流畅度 |

## QA 层级(融合 gstack /qa,3 级,L154-174)

| 级别 | 用途 | 时长 | 工具覆盖 |
|---|---|---|---|
| **Quick** | 5 分钟健康度速查 | <5 分钟 | 1 个浏览器 + 关键路径 |
| **Standard** | 完整用例覆盖 | 半小时-2 小时 | 多浏览器 + 全用例 |
| **Exhaustive** | 加压 + 渗透式测试 | 数小时-数天 | 加压工具 + 安全扫描 + 全维度 |

## 测试模式(源 SKILL.md L175-194)

### Diff-aware 模式(默认)

1. 跑 `git diff main...HEAD` 识别变更文件
2. 映射变更文件到受影响页面/路由
3. 检查本地服务端口(:3000 / :4000 / :8080 等)
4. **只测试受影响的页面**,不浪费时间在无关页面
5. 如未检测到本地服务,提示用户启动

## 健康评分系统(L197-227)

### 评分标准(8 类加权)

| 类别 | 权重 |
|---|---|
| 功能正确性 | 25% |
| 边界/异常 | 15% |
| 性能 | 15% |
| 安全 | 15% |
| 兼容性 | 10% |
| 无障碍 | 10% |
| 回归 | 5% |
| 用户体验 | 5% |

- **< 60 分**:不通过,需修复
- **60-79 分**:通过(可上线,但有改进项)
- **80-89 分**:良好
- **≥ 90 分**:优秀

## 响应式多屏测试(L228+)

- 桌面 / 平板 / 手机 3 套分辨率截图
- 同 1 份报告,便于横向对比

## 调用方式

- **无实参**: 走 Quick 级,5 分钟速查当前项目
- **有实参**(如 `/hltest E2E 标准级`): 指定级别和范围
- **典型耗时**: Quick 5 分钟,Standard 半小时-2 小时,Exhaustive 数小时-数天
